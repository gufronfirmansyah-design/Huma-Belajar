00 · Mulai dari sini — versi 1.5

Panduan ini menggantikan langkah login Google pada versi lama. Akun menggunakan username dan password. Password dikelola Supabase Auth (layanan pengelola akun), bukan disimpan dalam Spreadsheet atau tabel aplikasi.

1. Pilih kondisi Anda

  • Belum punya database / proyek kosong: ikuti kategori 01, bagian instalasi baru. Cukup satu file SQL.
  • Pernah menjalankan SQL dan sudah ada tabel profiles: ikuti bagian upgrade di kategori 01. Jangan menghapus data untuk mengganti login.
  • Baru gagal menjalankan upgrade 1.2 karena profiles tidak ada: periksa Table Editor. Bila benar-benar kosong, gunakan installer baru; jangan menjalankan upgrade 1.2 dahulu.
  • Website GitHub yang sudah ada bisa diperbarui. Tidak perlu menghapus repository.

2. Siapkan paket lengkap

  1. Ekstrak HUMA-BELAJAR-PAKET-LENGKAP.zip ke folder di laptop.
  2. Buka folder 05-PANDUAN.
  3. Klik dua kali INDEX.html. Panduan bisa dibaca tanpa internet.
  4. Jangan mengunggah seluruh paket ke GitHub. Folder backend, panduan lokal, dan alat bantu bukan isi website.
  5. Untuk melihat contoh aplikasi, klik JALANKAN-LOKAL.bat di folder utama. Jika diminta, pasang Node.js LTS satu kali sesuai panduan lokal pada kategori 07.

3. Urutan pemasangan

  1. 01 Supabase: buat proyek dan pasang SQL.
  2. 02 Username dan password: aktifkan provider Email, pasang fungsi accounts.
  3. 03 Hubungkan website: masukkan alamat proyek dan kunci publik, unduh konfigurasi.
  4. 04 Admin dan sekolah: buat admin pertama, kemudian sekolah, kelas, dan kode undangan.
  5. 05 Unggahan: pasang upload-material jika memakai berkas privat.
  6. 06 Materi dan soal: isi konten, latihan, dan bank soal.
  7. 07 GitHub: unggah website, uji, dan simpan cadangan.
  8. 08 Masalah umum: gunakan jika salah satu pemeriksaan gagal.

Tidak ada kewajiban membuat akun Google Console, OAuth Client ID, atau Client Secret.

4. Batas pemeriksaan

MODE DEMO hanya contoh lokal. Berhasil pada demo belum membuktikan database, login, atau pembatasan akun nyata bekerja. Sebelum digunakan siswa, jalankan daftar uji layanan nyata pada kategori 08.

Materi Drive yang dibagikan untuk siapa saja tetap merupakan materi publik. Mengunci menu aplikasi tidak mengubah izin berkas Drive tersebut.
