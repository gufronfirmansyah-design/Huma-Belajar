03 · Menghubungkan website ke Supabase

Sebelum mulai, database harus versi 1.5.0 dan fungsi accounts sudah dipasang (kategori 01–02).

A. Salin konfigurasi publik

  1. Buka proyek Supabase, klik Project Settings (ikon roda gigi).
  2. Buka Data API / API. Salin Project URL, bentuknya https://...supabase.co.
  3. Buka API Keys. Salin Publishable key (diawali sb_publishable_) atau legacy anon/public key.
  4. Jangan memilih Secret key, service_role, atau database password.
  5. Di paket laptop, klik BUKA-PENGATURAN.bat. Bisa juga membuka setup.html melalui JALANKAN-LOKAL.bat.
  6. Pilih mode Produksi / Supabase, isi Project URL dan kunci publik pada kolom yang tersedia.
  7. Klik Periksa koneksi.
  8. Harus terlihat database 1.5.0 dan layanan akun merespons. Jika gagal, perbaiki sesuai pesan; jangan menganggap login sudah bekerja.
  9. Klik tombol Unduh konfigurasi. Browser mengunduh config.public.json.
  10. Salin file tersebut ke 02-KODE-SUMBER/config.public.json, ganti file lama.
  11. Klik PERBARUI-WEBSITE.bat. Setelah berhasil, konfigurasi ikut ada di 01-WEBSITE-SIAP-UPLOAD.
  12. Untuk GitHub, unggah config.public.json produksi bersama website. Tidak cukup menyimpan konfigurasi pada halaman pengaturan di browser.

B. Pengaturan alamat website

  1. Buka Supabase → Authentication → URL Configuration.
  2. Isi Site URL dengan alamat GitHub Pages lengkap, termasuk nama repository jika ada.
  3. Simpan. Login password tidak menggunakan callback Google atau Authorized JavaScript origins.
  4. Gunakan HTTPS untuk website publik. Localhost hanya untuk uji laptop.
  5. Belum memiliki GitHub Pages? Lanjut kategori 07 untuk menerbitkan, lalu lengkapi Site URL.

C. Pemeriksaan nyata

  1. Buat admin pertama sesuai kategori 04.
  2. Buka website mode produksi. Tidak boleh ada pita MODE DEMO.
  3. Masuk dengan username adminutama dan password yang Anda buat di dashboard.
  4. Ganti password sementara saat diminta.
  5. Keluar lalu masuk kembali untuk memastikan password baru bekerja.
  6. Bila masih tampil halaman Google lama, muat ulang dengan Ctrl+F5 dan pastikan file terbaru sudah diunggah.

Konfigurasi publik boleh terlihat pengguna. Kunci server hanya berada di Supabase. Tidak ada langkah mengetik password admin di JavaScript.
