04 · Admin pertama, sekolah, guru, dan siswa

A. Buat admin pertama pada database baru

  1. Pastikan kategori 01–03 selesai: database 1.5.0, fungsi accounts terpasang, website mode produksi.
  2. Di Supabase klik Authentication → Users.
  3. Klik Add user → Create new user.
  4. Pada Email isi tepat adminutama@accounts.huma.invalid. Ini identitas internal, bukan email untuk menerima pesan.
  5. Buat password sementara sendiri, minimal 12 karakter. Simpan secara pribadi.
  6. Aktifkan Auto confirm user, lalu klik Create user.
  7. Di laptop buka 04-BACKEND/07-ADMIN-PERTAMA.sql, Ctrl+A, Ctrl+C.
  8. Di Supabase klik SQL Editor → New query, tempel seluruh isi, klik Run. Tunggu sukses.
  9. Buka website produksi. Isi username adminutama dan password sementara tadi.
  10. Ganti password saat diminta. Setelah berhasil menu Akun pengguna, Katalog bersama, dan Kelola tersedia.
  11. Keluar dan masuk kembali dengan password baru.

File ini hanya untuk admin awal pada database baru. Akun pertama yang mendaftar melalui website tidak otomatis menjadi admin. Untuk admin Google lama, gunakan pemindahan akun di kategori 02 agar UUID dan progres tetap terjaga.

B. Daftarkan sekolah dan kelas

  1. Di website, buka Sekolah & Akses.
  2. Pada bagian admin pusat, tambahkan nama sekolah. Sekolah Awal dari pemasangan dapat diubah sesuai sekolah Anda.
  3. Pilih sekolah tersebut, klik Buka sekolah. Selalu periksa nama sekolah aktif sebelum membuat kelas/kode.
  4. Buka Kelola → Kelas → + Tambah.
  5. Isi nama kelas, misalnya X A, dan tahun ajaran sesuai sekolah Anda. Klik Simpan perubahan.

C. Admin konten dan guru kontributor

  1. Admin pusat membuat akun calon guru melalui Akun pengguna, pilih Tanpa kelas. Berikan username/password sementara secara pribadi. Guru masuk, mengganti password, lalu memilih sekolah dan mengajukan akses guru.
  2. Admin pusat membuka Sekolah & Akses, memeriksa permohonan dan identitas pengguna, lalu menyetujui peran yang sesuai.
  3. Untuk tim katalog global, buka Katalog bersama → Tim konten. Pilih akun dan tentukan Admin konten atau Guru kontributor.
  4. Buat mapel melalui Kelola → Mata Pelajaran → + Tambah. Isi nama dan jenjang/tingkat, simpan.
  5. Buka Kelola → Penugasan Guru → + Tambah, pilih guru dan mapel, atur aktif, lalu simpan.
  6. Ulangi penugasan untuk mapel/tingkat lain. Guru tidak boleh memberi dirinya sendiri penugasan.

D. Hubungkan mapel bersama ke kelas

  1. Admin pusat memilih sekolah aktif.
  2. Buka Katalog bersama → Mapel yang digunakan kelas.
  3. Pilih kelas dan mapel, pilih Gunakan di kelas, lalu simpan.
  4. Ulangi untuk kelas lain. Materi yang sama dapat dipakai banyak kelas/sekolah tanpa disalin.

Mapel belum muncul pada siswa jika belum dihubungkan atau belum diterbitkan.

E. Kode kelas dan siswa

  1. Admin pusat membuka Sekolah & Akses, pastikan sekolah benar.
  2. Pilih kelas pada bagian kode undangan. Tentukan masa berlaku yang disediakan, klik tombol membuat kode, lalu salin hasilnya.
  3. Berikan kode hanya kepada kelas yang dituju.
  4. Siswa membuka website → Belum punya akun? Daftar siswa → mengisi nama, username, sekolah, kode undangan, dan password.
  5. Klik Buat akun siswa. Setelah berhasil, buka Belajar. Siswa yang sudah memiliki akun dapat bergabung ke kelas lain melalui Sekolah & Akses → Gabung kelas.

Kode undangan bukan password dan bukan kode komisi referral. Pemegang kode valid dapat mendaftar sebagai siswa; tim tetap perlu memeriksa daftar siswa.

F. Admin sekolah pemantau

  1. Admin pusat membuat akun calon pemantau melalui Akun pengguna, pilihan Tanpa kelas. Pemantau masuk, mengganti password, memilih sekolah, lalu mengajukan akses (permohonan awal tampil sebagai guru; admin pusat menetapkan peran pemantau pada persetujuan).
  2. Admin pusat membuka permohonan, memilih Admin sekolah (hanya memantau), lalu mengaktifkannya.
  3. Pemantau memuat ulang website, memilih kelas, dan membuka Progres.
  4. Uji menggunakan akun pemantau: hanya progres/skor sekolahnya yang terlihat; tidak ada hak mengubah soal, nilai, atau kode kelas.

Gunakan akun percobaan berbeda untuk admin, guru, siswa, dan pemantau. Pemilih peran MODE DEMO bukan pengujian keamanan akun produksi.
