05 · Mengaktifkan unggahan gambar dan PDF privat

Bagian ini diperlukan untuk gambar soal dan berkas privat. Materi Drive publik serta YouTube menggunakan tautan dan tidak memerlukan unggahan ke Supabase.

Edge Function berarti layanan kecil di server. Nama layanan dalam aplikasi harus tepat upload-material.

A. Memasang kode melalui dashboard

  1. Buka Supabase → proyek HUMA BELAJAR → Edge Functions.
  2. Klik Deploy a new function. Pilih Via Editor / Open Editor bila pilihan metode ditampilkan.
  3. Gunakan fungsi kosong atau template dasar yang tersedia. Pada editor, buka file index.ts.
  4. Di laptop, buka 04-BACKEND/functions/upload-material/index.ts menggunakan Notepad.
  5. Tekan Ctrl+A lalu Ctrl+C untuk menyalin seluruh kode.
  6. Kembali ke editor Supabase, klik isi index.ts → Ctrl+A → Ctrl+V untuk mengganti contoh bawaan.
  7. Isi nama fungsi upload-material pada kolom nama/deploy. Jangan memakai spasi atau huruf besar.
  8. Klik Deploy function. Tunggu berhasil. Pastikan daftar fungsi menampilkan nama yang benar.

Kode ini memakai variabel layanan Supabase di sisi server: SUPABASE_URL, SUPABASE_ANON_KEY, SUPABASE_SERVICE_ROLE_KEY. Jangan menyalinnya ke config website. Jika log mengatakan variabel tidak tersedia, periksa konfigurasi lingkungan proyek; jangan mengganti kode dengan rahasia yang ditaruh di GitHub.

B. Memeriksa tempat penyimpanan

  1. Buka menu Storage.
  2. Cari bucket bernama learning. Bucket berarti tempat penyimpanan berkas.
  3. Bucket ini dibuat oleh SQL dan harus Private, bukan Public. Jangan membuatnya publik supaya gambar “mudah dibuka”.
  4. Jika tidak ada, kembali ke kategori 01 dan periksa keberhasilan pemasangan SQL.

C. Uji dari aplikasi, bukan tombol Test tanpa akun

  1. Login website sebagai guru yang ditugaskan pada suatu mapel atau sebagai admin pusat/konten.
  2. Buka Kelola → Materi → + Tambah. Pilih mapel, subbab, judul, serta jenis Gambar privat.
  3. Pilih satu PNG/JPG kecil yang valid, isi teks jika perlu, simpan sebagai draf atau materi uji yang sesuai.
  4. Setelah diterbitkan pada kelas uji, buka sebagai siswa berhak dan coba tombol membuka berkas.
  5. Coba akun tanpa izin mapel. Berkas tidak boleh terbuka hanya karena seseorang mengetahui path-nya.

D. Jika unggahan menghasilkan 401 / Invalid JWT

  1. Keluar lalu login ulang untuk memperbarui sesi, coba lagi.
  2. Buka Edge Functions → upload-material → Logs / Invocations dan cocokkan waktu percobaan.
  3. Jika penolakan terjadi di gateway sebelum kode berjalan, periksa pengaturan fungsi Verify JWT / Enforce JWT verification. Pada konfigurasi kunci yang tidak didukung verifikasi gateway lama, layanan ini dapat menggunakan verifikasi pengguna di dalam kode: nonaktifkan pemeriksaan gateway khusus fungsi ini bila memang diperlukan.
  4. Jangan menghapus pemeriksaan getUser() dan upload_permission dari kode. Keduanya tetap memeriksa sesi dan hak mapel pada setiap permintaan.
  5. Uji lagi akun yang sah dan permintaan tanpa login. Jika fungsi tanpa login menerima unggahan, hentikan penggunaan dan periksa pemasangannya.

Jangan menonaktifkan keamanan tabel atau membuat Storage publik untuk mengatasi error. Batas awal 10 MB per berkas, PDF/JPEG/PNG/WebP; isi berkas diperiksa kembali di server.

Rujukan pemeriksaan sesi/gateway: Supabase — pengamanan Edge Functions.

Rujukan: pemasangan fungsi lewat dashboard Supabase. Nama tombol dapat bergeser; langkah kode mengikuti berkas yang benar-benar disertakan dalam HUMA BELAJAR.
