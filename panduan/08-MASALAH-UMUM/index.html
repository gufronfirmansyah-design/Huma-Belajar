08 · Memeriksa masalah dan mencoba akun nyata

Username/password salah

  1. Gunakan username, bukan alamat Google atau email internal.
  2. Periksa huruf kecil, titik, dan spasi yang tidak sengaja tersalin.
  3. Coba password terakhir yang diberikan atau yang sudah Anda ubah.
  4. Jika lupa, hubungi admin pusat melalui sekolah. Admin mereset password melalui menu Akun pengguna.
  5. Pastikan provider Email di Supabase aktif.

Layanan accounts belum dapat dihubungi / 401 Invalid JWT

  1. Buka Supabase → Edge Functions. Pastikan fungsi bernama accounts ada dan deployment berhasil.
  2. Buka editor fungsi. Harus ada index.ts dan handler.js dengan isi dari paket versi 1.5.
  3. Buka Details fungsi dan nonaktifkan Verify JWT with legacy secret, lalu simpan. Fungsi memeriksa sendiri token untuk tindakan admin.
  4. Jalankan Periksa koneksi di website. Jangan menonaktifkan pemeriksaan token dalam kode handler.
  5. Jika respons 500, periksa Logs untuk pesan pemasangan. Jangan mencetak body formulir, password, atau token ke log.

Terlalu banyak permintaan

Tunggu satu menit sebelum mencoba ulang. Login dibatasi per username dan secara keseluruhan; pendaftaran juga dibatasi agar tidak dipakai membuat akun massal sembarangan. Impor admin dijalankan bertahap. Baris yang gagal tidak dianggap berhasil.

Akun belum siap / username belum dibuat

Akun Google lama belum mempunyai username. Pemilik proyek memindahkan admin pertama, kemudian admin memindahkan akun lain melalui Akun pengguna. Ikuti kategori 02 bagian F. Jangan menghapus user lama.

Jika halaman berhenti pada error startup, klik Keluar lalu masuk kembali setelah admin memperbaiki akun.

Wajib ganti password / perubahan lain belum selesai

Password sementara harus diganti. Isi password saat ini dan password baru yang berbeda, minimal 12 karakter. Jika perubahan terputus di server, gunakan pemulihan kategori 02 bagian G. Jangan menghilangkan pagar perubahan password hanya dari tampilan.

Kode undangan kelas tidak valid

Periksa sekolah yang dipilih, kode lengkap, dan masa berlaku. Minta kode baru kepada admin. Jangan memasukkan nama kelas sebagai kode. Bila sekolah belum ada, admin pusat harus mendaftarkannya dahulu.

Database belum siap / profiles tidak ada

Jalankan select public.public_status(); di SQL Editor. Target 1.5.0. Jika database kosong gunakan 00-INSTALASI-BARU.sql. Jika sudah ada data gunakan urutan upgrade pada kategori 01. Jangan menjalankan installer awal pada database lama.

Masih MODE DEMO / masih tombol Google

  1. Salin config.public.json yang diunduh ke 02-KODE-SUMBER.
  2. Jalankan PERBARUI-WEBSITE.bat.
  3. Unggah isi 01-WEBSITE-SIAP-UPLOAD ke tempat index.html di GitHub.
  4. Tunggu deployment sukses, tekan Ctrl+F5. Pastikan nama konfigurasi tidak menjadi config.public (1).json.
  5. Buka VERSION.txt pada website. Target 1.5.0.

Siswa masuk tetapi mapel kosong

Periksa keanggotaan siswa, kelas aktif, hubungan mapel-ke-kelas dalam Katalog bersama, dan status terbit mapel/bab/subbab/materi. Akun tanpa kelas tidak otomatis memperoleh semua materi.

Gambar/PDF privat gagal diunggah

Periksa kategori 05: fungsi upload-material terpasang, bucket learning privat, sesi aktif, password sementara sudah diganti, dan guru punya penugasan mapel. Jangan membuat bucket publik untuk mengatasi error.

PDF Drive/YouTube tidak tampil

Klik Buka di tab baru. Periksa izin Drive Siapa saja yang memiliki link → Pelihat, link berkas bukan folder, serta video mengizinkan pemutar tertanam. Link Google Slides docs.google.com/presentation belum diterima pembaca Drive saat ini.

Daftar pengujian layanan nyata sebelum dipakai siswa

Pengujian lokal dan layanan tiruan tidak menggantikan daftar ini. Gunakan akun uji dan dua sekolah/kelas uji.

  1. Buat admin, ganti password sementara, keluar, lalu masuk kembali.
  2. Daftarkan siswa A dengan kode sekolah A. Kode salah dan kode sekolah lain harus ditolak.
  3. Daftarkan siswa B di sekolah B. Siswa A tidak dapat melihat hasil privat B, termasuk lewat permintaan langsung.
  4. Buat satu siswa lewat admin; akun belum bisa membuka data privat sebelum mengganti password.
  5. Impor Excel dua siswa. Ulangi file: tidak ada akun/keanggotaan ganda.
  6. Putuskan jaringan saat impor. Baris gagal terlihat; ulangi tanpa menggandakan baris berhasil.
  7. Reset password siswa. Password lama tidak dapat digunakan untuk login baru, sesi lama tidak dapat membaca data setelah reset diselesaikan dan password baru diaktifkan.
  8. Coba akun guru tanpa penugasan, kemudian beri satu mapel. Guru hanya mengelola mapel yang diizinkan.
  9. Coba admin sekolah: hanya laporan sekolahnya, tanpa tombol maupun hak server untuk membuat/reset akun.
  10. Buka URL berkas privat tanpa izin: harus ditolak. Tautan bertanda tangan yang sudah diterbitkan dapat berlaku sampai masa kedaluwarsanya; bukan pemutusan unduhan instan.
  11. Coba guest: hanya contoh subbab pertama Bab 1 tiap mapel yang dipilih sebagai contoh publik.
  12. Coba pada HP dan laptop, termasuk alamat GitHub Pages dalam subfolder.
  13. Matikan koneksi saat menyimpan formulir: tidak muncul sukses palsu dan isian tetap ada.
  14. Periksa paket website tidak mengandung secret atau file hasil password.

Informasi saat meminta bantuan

Kirim kategori/langkah dan pesan error. Tutupi nama siswa, password, secret key, dan token pada screenshot. Jangan kirim kredensial. Jangan menghapus database untuk mencoba ulang.
