LANGKAH 01

Coba dulu, tanpa akun layanan.

Mode demo dapat langsung dipakai sebagai siswa, guru, dan admin. Data contoh hanya disimpan di browser ini. Tidak ada data siswa sungguhan.

Buka aplikasi →

Untuk menjalankan di laptop, klik JALANKAN-LOKAL.bat. Mengubah konfigurasi tidak menghapus data produksi.

LANGKAH 02

Pasang database & login.

  1. Buat proyek di dashboard Supabase ↗.
  2. Database kosong: jalankan 04-BACKEND/00-INSTALASI-BARU.sql. Database lama: ikuti jalur upgrade pada panduan kategori 01; jangan mengulang skema awal.
  3. Aktifkan provider Email/password, matikan pendaftaran langsung dan provider Google. Pasang Edge Function accounts sesuai kategori 02.
  4. Daftarkan alamat website pada Site URL dan Redirect URLs, termasuk subfolder repository jika digunakan.
  5. Untuk unggahan, terbitkan Edge Function upload-material menggunakan berkas dalam folder backend.
  6. Buat admin pertama melalui Authentication → Users lalu jalankan 07-ADMIN-PERTAMA.sql. Ikuti kategori 04; jangan menulis password dalam SQL.

Jangan jalankan skema awal berulang kali pada proyek berisi data. Panduan lengkap tersedia di folder 05-PANDUAN.

LANGKAH 03

Hubungkan ke proyekmu.

Yang diisi hanya konfigurasi publik. Pemeriksaan akses pengguna tetap dilakukan oleh backend.

Gunakan publishable key atau legacy anon key. Jangan masukkan secret key atau service-role key.

Berkas config.public.json yang diunduh tidak otomatis mengubah aplikasi. Ganti berkas dengan nama yang sama di kode sumber, lalu klik PERBARUI-WEBSITE.bat. Jika mengedit langsung di GitHub, ganti hanya berkas konfigurasi pada akar website.

LANGKAH 04

Unggah. Buka. Mulai belajar.

GitHub Pages

Untuk demo/pembelajaran nonkomersial yang sesuai ketentuan:

  1. Ekstrak ZIP WEBSITE-SIAP-UPLOAD.
  2. Unggah isinya ke akar repository, termasuk .nojekyll.
  3. Settings → Pages → Deploy from a branch → main → / (root).
  4. Buka tautan yang diberikan GitHub. Periksa ulang alamat pengalihan login bila memakai backend.

Alternatif: Cloudflare Pages

Direct Upload menerima paket website yang sama. Cocok untuk jalur produksi yang direncanakan dalam PRD.

Panduan unggah resmi ↗

GitHub Pages memiliki batas penggunaan untuk bisnis/layanan komersial dan transaksi sensitif. Jangan menaruh data siswa, rahasia, atau konten privat di repository/paket publik. Baca ketentuannya ↗

Memperbarui satu fitur

Ubah modul terkait pada kode sumber, lalu klik PERBARUI-WEBSITE.bat. Folder 07-UPDATE-TERAKHIR berisi berkas yang berubah sejak versi terakhir yang Anda tandai sudah diunggah. Unggah berkas tersebut ke lokasi yang sama di GitHub. Setelah unggahan berhasil, klik TANDAI-SUDAH-DIUPLOAD.bat untuk menyimpan patokan pembaruan. Jika belum ada patokan, semua berkas disertakan.

Menambah halaman baru cukup dengan satu modul dan satu entri di features.js. Perubahan konten melalui panel guru/admin langsung tersimpan di database; tidak perlu mengunggah ulang website.
